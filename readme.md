## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use the Live Server extension in VS Code.
3. Test the navigation and contact form. The contact form opens the visitor's default email app; it does not store or send messages through a backend.

## Deploy on Netlify (free static hosting)
1. Go to https://app.netlify.com/drop
2. Sign in or create a Netlify account.
3. Drag the extracted `faizan-portfolio` folder onto the Netlify Drop page.
4. Wait for the deploy to finish. Netlify will give you a public `*.netlify.app` URL.
5. In Netlify, open **Site configuration** / **Domain management** to rename the site subdomain if the name is available.

For future updates, edit the files and drag the folder onto Netlify Drop again, or connect a GitHub repository in Netlify for automatic deployments.

## Resume PDF
Open `resume.html` from the portfolio and choose **Print / Save as PDF**. Choose **Save as PDF** in the browser print dialog. There is no hosted PDF download; the resume links open the printable page.
